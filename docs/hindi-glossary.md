# FuelBook Hindi glossary

The app is bilingual: English and Hindi in Devanagari. This file fixes the wording so
every screen says the same thing.

## Register — read this first

Pump owners and staff speak **Hinglish**. They say "शिफ़्ट", "नोज़ल", "रेट", "बैंक",
"कैश" — not "पाली", "तुंड", "दर", "अधिकोष". Translating into literary Hindi makes the
app **harder** to use. Keep the everyday word and write it in Devanagari.

- Use the loanword when that is what people say: शिफ़्ट, नोज़ल, टैंकर, रेट, स्टॉक, बैंक,
  चेक, लाइसेंस, डीज़ल, पेट्रोल, मीटर, डिप, कैशियर.
- Use plain Hindi where plain Hindi is what people say: उधार, बकाया, वसूली, खर्च, कर्मचारी,
  हाजिरी, बिक्री, कमी, तारीख़, नकद.
- Address the user as आप, and prefer imperatives ending in -एँ: सेव करें, जोड़ें, हटाएँ.
- Do not translate data the user typed (customer names, expense heads, pump names).
- Money stays ₹ with Indian digit grouping in both languages. Latin digits in both —
  Devanagari numerals would be unreadable on a keypad-entered figure.
